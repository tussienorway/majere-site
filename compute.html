Compute request

Summary: about 275 H100 GPU-hours (or a TPU v4/v5e equivalent) over ~12 weeks for scaled supervised fine-tuning and ablations of a 7–8B Apache-2.0 model for Norwegian (Bokmål and Nynorsk) and reliable tool calling, after the local pilot on our own GPU. The result is released as open adapters and 4-bit GGUF files that run on one 16 GB GPU. Applicant: Thomas Austenaa, independent researcher, Grimstad, Norway (no institutional affiliation).

How the estimate was made: FLOPs ≈ 6·N·T (N parameters, T training tokens), 35% hardware utilisation, plus a 50% buffer. It will be rescaled once the full pilot has run (research-plan.md).

Pilot base (decided 2026-10-13): Qwen3-8B with thinking off. NorMistral stays as a comparison and for a later fluency check (Approach).

Measured on our own GPU (2026-10-13): QLoRA smoke run, Qwen3-8B 4-bit NF4, rank 16, max length 1024, 50 steps on an RTX 5060 Ti 16 GB: peak VRAM 9.41 GiB, 15.3 s/step, ~327 training tokens/s. That is about 1.2M tokens/hour, so 100M tokens take about 85 hours per seed on that card. Several seeds, data mixes and ablations at that scale are not practical on one card, which is the reason for the request. The full pilot SFT has not been run yet, so there are no fine-tuned results.

Evidence so far

  • NO-FC v0 (40 hand-written seed tasks) and v1 (120 tasks, 80/40 dev/test split): Data & evaluation · majere-nofc results
  • v0, historical: qwen3:8b scored 0.825 (33/40) exact match on the 40 seed tasks.
  • NO-FC v1 baselines, no fine-tuning (Ollama, RTX 5060 Ti 16 GB, exact match, test 40 / dev 80): qwen3:8b thinking off, native tools 0.825 / 0.775; thinking off, prompt tools 0.800 / 0.762; thinking on, native tools 0.800 / 0.688; NorMistral-11B-thinking Q4, prompt tools 0.325 / 0.287 (call-name accuracy 0.11).
  • QLoRA smoke run: Qwen3-8B, 9.41 GiB peak VRAM, 15.3 s/step, ~327 tokens/s (see above).
  • Technical preprint (4 pages): PDF · Markdown
  • Open evaluation set + harness: huggingface.co/datasets/tussienorway/majere-eval-no-tools
  • Code: majere-nofc · Research log and decisions: majere-research · Site: majere.thomasaustenaa.no
