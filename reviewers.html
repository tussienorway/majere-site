For reviewers: the project on one page

GoalFine-tune an Apache-2.0 7–8B model (pilot base: Qwen3-8B, thinking off, chosen 2026-10-13; NorMistral kept as comparison) for Norwegian Bokmål/Nynorsk and reliable function calling, running 4-bit on one 16 GB GPU
NoveltyThe first open Norwegian function-calling benchmark (NO-FC), plus open Norwegian tool-calling adapters
EvaluationNorEval, EuroEval, BFCL and NO-FC, compared with untouched base models. Pre-registered success criterion.
Ask≈ 275 H100 GPU-hours or a TPU equivalent (method on the compute page). This will be updated with measured pilot numbers.
Timeline12 weeks: pilot (own GPU) → scaled runs (grant) → release
OutputsOpen code, weights, benchmark and technical report. Negative results are published too.
StatusNO-FC v0 and v1 done. v1 test baselines: qwen3:8b 0.825, NorMistral-11B-thinking 0.325. QLoRA smoke run on 16 GB done (9.4 GiB peak, ~327 tok/s). No fine-tuned results yet.
