Majere: Multi-Persona Deliberation ("Archetype Council") as an Architecture for Affect-Modulated, Self-Monitoring Language Agents

Open, independent research into whether an internal council of personas, with an explicit affect state, makes language agents more consistent, better calibrated and easier to control.

Abstract

Majere is an agent architecture in which several "archetype" personas deliberate before the agent acts. The council maintains an internal affect state (valence/arousal) and a tunable impulsivity parameter that trades speed for deliberation. We ask four measurable, falsifiable questions about behavioural consistency, the speed–quality trade-off, calibration and self-monitoring, and functional indicators from the consciousness-science literature. Every comparison is against baselines with the same token budget. We make no claim that the system has feelings or consciousness; negative results will be published.

Majere is one project of the independent lab at ai-agenter.no, alongside SafeRoute-Hermes (provenance- and risk-aware model routing). The council can be seen as an internal router: an impulsive path uses a small model, a deliberative path uses the full council or a verifier.
